# 밥드컵

친구들이 밥 월드컵 + 못 먹는 것 체크를 하면, 다 같이 납득할 메뉴 TOP 3를 이유와 함께 골라주는 그룹 메뉴 추천 앱. (이전 이름: 밀픽 → 냠픽)

- `index.html` : 웹 프로토타입 (폰 한 대를 돌려가며 사용)
- `bgm.mp3` : 월드컵 화면 배경음악 (약 40초, 무한 반복)
- `manifest.webmanifest`, `icon-*.png` : 폰 홈 화면에 앱처럼 설치하기 위한 설정
- `algorithm/` : 추천 점수 알고리즘 원본 (Python) + 메뉴 데이터(가격대·사진 포함)

음식 사진: Wikimedia Commons (각 사진의 자유 라이선스를 따름, 작가·라이선스는 앱 안 '가격 근거와 사진 출처'에 표시)
